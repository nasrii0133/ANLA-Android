# ANLA

ANLA, karmaşık belge ve metinleri kullanıcılar için daha anlaşılır hâle getirmeyi amaçlayan bir Android uygulamasıdır.

## Projenin Amacı
Kullanıcıların günlük hayatta karşılaştıkları resmî yazıları, faturaları ve bilgilendirme belgelerini daha kolay anlamalarına yardımcı olmak.

## Planlanan Özellikler
- Kamera ile belge tarama
- OCR ile metin tanıma
- Tanınan metni kontrol etme ve düzenleme
- Yapay zekâ ile sade Türkçe açıklama
- Önemli noktaları listeleme
- Açıklama geçmişini kaydetme

## Kullanılacak Teknolojiler
- Kotlin
- Android Studio
- Jetpack Compose
- Google ML Kit
- Room Database
- REST API
